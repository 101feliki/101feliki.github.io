How I work

Production is the starting line, not the finish

Anyone can make an API return JSON. What I care about is what happens after launch: will it hold under load, will a bad query take it down, will we know when someone attacks it, can a new developer run it from the README, and can we restore it if the server dies?

More about me {{icon:arrow}}

Secure by default

Parameterised SQL, least-privilege database accounts, query time limits, rate limits, role-based access and audit logs.

Tested

Integration tests against a real database. Nothing is committed or deployed unless every test passes.

Documented

OpenAPI/Swagger for every endpoint, plain-English READMEs, and a runbook for moving to a new server.

Privacy-aware

Kenya Data Protection Act in mind: consent before tracking, data deleted on schedule, CVs never public.
