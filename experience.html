Mustek East Africa: website platform

  • Designed and built the Express 5 / PostgreSQL API behind the website and admin portal: catalogue, orders, enquiries, blog, careers and job applications.
  • Built staff roles (admin, sales, marketing, HR) with per-permission checks, an audit log, and a security dashboard with an IP-geolocation attack map and email alerts.
  • Hardened the database: a least-privilege account for the API, query time limits and an injection test suite, so one bad query can't take the site down or drop a table.
  • Cut product photo weight by about 77% (thumbnails 92%) with an automatic WebP pipeline.
  • Added consent-based personalisation that complies with Kenya's Data Protection Act: anonymous popularity for everyone, personal ranking only after "Accept", deleted on withdrawal.
  • Run the production server: Docker, nginx, pm2, TLS, nightly backups, and a written runbook so the system can move to a new server with nothing left out. 76 automated tests gate every deploy.

Movit: HR and sales systems
